# RuckOps — Project 1 Output

Validated app idea and locked MVP scope for **RuckOps**, a dedicated rucking and running tracker for the military and serious fitness community.

## Files in this package

- `APP_IDEA_SUMMARY.md` — Validated concept: app name, target user, core feature, differentiator, platform, key risk
- `MVP_SCOPE.md` — **Locked** MVP scope: screens, features, exclusions, data model, services, pricing
- `HANDOVER_PROMPT.md` — Ready-to-paste prompt for Project 2 (App Designer)
- `github/PUSH_COMMAND.txt` — One-line terminal command to set up the GitHub repo

## What's next

1. Run the command in `github/PUSH_COMMAND.txt` from your Ubuntu terminal to unzip the folder and create a local Git repo.
2. Create a new repo on GitHub (https://github.com/new) and follow the on-screen instructions to push it.
3. Open a new chat for **Project 2: App Designer**, upload `RuckOps-Project1.zip`, and paste the contents of `HANDOVER_PROMPT.md`.

## Important

The MVP Scope is **locked**. Every downstream project (Designer, Content Writer, Developer Briefer, MVP Builder) will treat the feature list as the source of truth. Anything new goes into v2 — not the MVP.
